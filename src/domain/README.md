# 领域层

此目录保存与协议和持久化方式无关的规则，不新建第二套状态仓库。

- `conversations/`：解析后会话动作的归属与状态规则，包括归档/删除前的忙碌判断、计划任务目标归属。微信文本命令格式由接口层解析。
- `messages/`：真实发送人、外部消息与任务键的身份；本轮材料关联与稳定 ID。
- `tasks/`：会话生命周期规则与执行状态投影；取消信号由基础设施运行时实现。
- `delivery/`：收件回执、版本提示去重及已确认失败的终答复恢复条件。未知投递结果不自动重发。
- `schedules/`：重复计划与时区计算，包括夏令时跳过和重复时间处理。
- `updates/`：版本号、已安装版本标记和升级比较。

领域函数接收已有状态或归一化值并返回判断；微信原始消息字段、API 错误码、SQLite、文件、RPC、HTTP 和消息发送留在适配器、应用或接口层。材料名称只保留文件名，不把本机父路径传入模型。会话选择、归档、删除与恢复的执行协调位于 `src/application/`，使用领域判断后再执行持久化和外部调用。
