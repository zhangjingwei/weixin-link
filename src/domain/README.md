# 领域层

此目录保存与协议和持久化方式无关的规则，不新建第二套状态仓库。

- `conversations/`：会话命令、归档/删除前的忙碌判断、计划任务目标归属。
- `messages/`：真实发送人、外部消息与任务键的身份；本轮材料关联与稳定 ID。
- `tasks/`：按用户隔离的取消作用域、会话生命周期、执行状态投影。
- `delivery/`：收件回执、版本提示去重及已确认失败的终答复恢复条件。未知投递结果不自动重发。
- `schedules/`：重复计划与时区计算，包括夏令时跳过和重复时间处理。
- `updates/`：版本号、已安装版本标记和升级比较。

领域函数接收已有状态或归一化值并返回判断；微信原始消息字段、API 错误码、SQLite、文件、RPC、HTTP、消息发送和提示文案留在适配器、应用或接口层。材料名称只保留文件名，不把本机父路径传入模型。旧 `src/core/` 路径对已迁移规则提供兼容导出。会话选择、归档、删除与恢复的执行协调仍在 `src/core/`，使用领域判断后再执行持久化和外部调用。
