# 应用层

应用用例在此目录运行，组合根注入现有会话、持久化和出站能力，不另建状态仓库。

- `intake/`：游标前收件保存、普通消息入队、意图判定与消息分流。微信 SDK 解析和控制命令识别仍由接口适配器处理。
- `tasks/`：持久任务逐会话执行、取消检查与恢复；任务记录仍由原有 `DurableJobs` 保存。
- `schedules/`：计划请求授权、到期任务路由、计划状态与重试。提醒经微信 Presenter 投递。
- `notifications/`：版本提示和失败终答复恢复；保留未知投递结果，不自动重发。
- `ports/`：校验组合根的外部能力并暴露窄接口，不向用例暴露 SDK 客户端或凭据。

旧 `src/core/` 入口暂时重导出应用实现，供既有调用方逐步迁移。领域规则、恢复细节及状态存储仍在 `src/core/`，后续迁移时须保留收件确认、任务插入、取消与恢复语义。
