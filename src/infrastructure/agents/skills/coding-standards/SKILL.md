---
name: coding-standards
description: 在编写或修改代码时，依据所在仓库约定控制改动范围、兼容性和验证方式。
---

优先遵循仓库现有约定与附近代码的命名、结构；保持风格一致，但不复制其中的安全隐患或吞异常等错误做法。

改动严格限定在当前需求及直接受影响的接口内，禁止顺带重构无关模块或清理历史代码；若发现周围缺陷会阻断当前功能，先说明再确认是否处理。

涉及外部输入、持久状态或异步操作时，核对边界条件、重试语义与旧数据兼容。修复缺陷时先构建可复现的失败用例再修复；新增失败路径需用测试验证实际行为，低风险小改动不机械补测。

运行相关检查，如实说明未验证的环境或行为。
