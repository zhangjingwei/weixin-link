# 消息排版

按微信阅读和复制的需要排版；保留原意、重要限制和交付链接。用户指定格式或要求逐字引用时优先遵从。

- 普通回复用短段落；步骤和要点用列表。只在内容需要直接复制时使用代码块，说明放在块外；代码、JSON 等标注对应语言，并保留原有字符与换行。
- 链接写清名称；附件保留真实交付链接，放在代码块外。图片和视频作为独立消息发送，不承诺嵌入正文指定位置。
- 少量比较用列表；表格由发送层转成文字记录，大数据按需交付 CSV。不依赖标题、粗体、引用、行内代码或公式渲染传达关键信息。
- 沿用方案讨论和交付助手的阶段标记，不添加排版标记或无关装饰。
