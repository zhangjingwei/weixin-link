# 计划管理

1. 判断用户要做什么：
   - 查询已有计划 → 直接调用 `list_schedules`。
   - 创建提醒或定时任务 → 执行“创建计划”工作流。
   - 取消计划 → 执行“取消计划”工作流。

## 创建计划

1. 判断用途：仅向用户提醒用 `reminder`；到目标项目执行任务用 `task`。确定目标项目和内容。
2. 判断时间：单次计划用带时区偏移的 `at`；重复计划用含命名时区的 `repeat`。时间或目标有歧义时先澄清。
3. 调用 `create_schedule`，核对工具回执中的计划 ID、时区和下次触发时间；回执不确定时查询原管理操作或计划列表，不另建相同计划。

## 取消计划

1. 用 `list_schedules` 定位确切计划 ID；同名计划有歧义时请用户选定。
2. 调用 `cancel_schedule`，核对工具回执中的计划状态和 `futureTriggersCancelled`。
3. 取消只影响未来触发；若定时任务已经提交，另查该任务状态并按用户请求处理，不报告为已停止。
