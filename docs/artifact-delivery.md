# 文件交付与临时文件生命周期

## 链接与交付状态

最终回复中的本地 Markdown 链接用于显式交付文件。绝对路径直接使用；相对路径按当前会话工作目录解析，不允许通过相对路径逃出该目录。`sandbox:` 绝对路径保留兼容。HTTP/HTTPS 外链和代码示例不触发附件发送。普通源码位置引用应使用纯路径。

链接识别与微信文字呈现共用链接语法。本地链接显示为“名称〔附件〕”，实际文件通过文件卡片交付，不伪装成微信内可点击的下载入口。缺失、越界、不支持的文件以及准备异常会进入附件错误记录；即使文字发送成功，整组交付也保持 `partial`。微信接口确认接收不等于收件人已阅读或下载。

## 默认存放位置

新建或恢复会话时，智能体收到该会话专用的绝对交付目录：账号私有状态目录下的 `deliverables/<会话哈希>/`。临时报告、导出、压缩包等副本应优先生成在这里，目录使用 0700 权限。安装账号状态目录应保持在代码仓库之外。该路径是交付约定与导出边界，不是模型的文件系统沙箱。

打包会将文件复制到同账号私有的 `outgoing/<会话哈希>/<包ID>/`，文件权限为 0600，并记录内容摘要。只有当前会话的私有生成目录可作为该会话的交付来源。实际传输使用快照，后续原件变化不会改变本次附件。

旧的 `outputs/` 显式交付链接继续兼容。不会自动更改任意项目的 Git 配置；本项目忽略 outputs，但其他仓库可能没有同样规则。不要把临时工作信息生成在源码目录，也不要把 `.gitignore` 当成对已跟踪文件的保护。

## 成功、失败与清理

- 整组文字、附件均获发送接口确认且无准备错误后，为快照写入过期标记。
- 只对当前会话私有 `deliverables/` 内、与打包时内容摘要仍相同的普通原文件进行删除。源码、项目内 outputs、用户原始输入及原件的替换内容均不自动删除；符号链接不作为可删除原件。
- 成功快照从首次确认开始保留 7 天，用于“结果”主动重发。重发不延长保留期限。
- 到期后不再允许读取快照；物理清理在账号服务初始化、该会话下一次打包时执行，因此空闲时可能晚于到期时间。清理不扫描其他会话，也不删除未标记完成的包。
- 失败、部分失败、取消或结果未知的附件保留，以支持核对和恢复；不会因超时而自动重发或删除。磁盘占用及保留中的旧结果需由账号所有者按需要管理。
- 升级前生成在仓库中的文件、未带完成标记的旧快照不批量迁移或删除，避免误删项目资料。

普通删除不是安全擦除，也不会撤回微信服务器、收件设备、备份或 Git 历史中的副本。上述机制主要防止新临时交付文件进入项目仓库，并限制已确认交付快照的有效保留期。
