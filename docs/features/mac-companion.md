# Weixin Link for Mac（首版）

独立的 macOS 客户端，只连接同一台电脑、同一系统用户的 Weixin Link 服务。打开应用默认查看微信当前会话的近期任务消息和文件。无需登录第二个 Codex，也不会打开或关闭 Codex 桌面应用。

1. 手动升级本机服务到包含本功能的提交。需要自行构建客户端时，在源码根目录运行 `./desktop/mac/build.sh`（macOS 13+，需要 Swift 和 macOS SDK），再运行 `open 'desktop/mac/build/Weixin Link.app'`。
2. 从微信发一份测试文件。点原消息下的附件即可预览；关闭预览返回原阅读区。文件须仍在本机。首版不从 Mac 上传新附件。
3. 点「在 Mac 接手」。如果任务仍可接收补充，输入框显示「补充到正在执行的任务」；若任务已结束，可向原会话发送下一条。目标发生变化时须重新确认草稿。结果继续按原有微信投递规则发送。
4. 在微信发送「操作端」可查询当前持有者。Mac 持有时，回复提示中的「微信接手 数字」即可接回，不需要 Mac 在线。只读端的输入不排队；过期编号不会覆盖后来一次交接。

左栏列出本账号未归档、未删除的会话。选中背景表示 Mac 正在看哪一条，手机图标标出微信当前会话。点左栏只浏览：右侧消息和文件跟随选中项，其他会话保持只读。返回带手机图标的会话后，可以接手或继续输入。草稿按会话、任务和接手版本隔离。

接手按安装账号生效，重启后保留。显示最近 20 个任务和留存结果，不是微信聊天记录归档。客户端只通过账号私有 Unix socket 连接，可用 `WEIXIN_LINK_MAC_SOCKET` 指向隔离测试服务。构建脚本只生成当前 CPU 架构的本地签名应用，不安装或重启服务。

右侧以气泡显示你的消息。助手回复按段落、标题、列表和引用排版；围栏代码保留原缩进，可横向滚动或复制，不会执行。活动任务有进度时，展开「当前任务进展」可看最近最多六项摘要，任务结束后收起并移除。左栏按已绑定的原生项目 ID 分组，使用工作目录简称显示项目；未绑定的会话列为「独立会话」。⌘K 搜索项目或会话名称。网页链接使用默认浏览器。选中文件才展开预览，窄窗用覆盖面板；PDF 可翻页、缩放，图片可放大查看，文本可阅读复制，Office 和媒体使用系统预览。ZIP 和未知格式仅提供 Finder 定位。当前任务提供实际差异且未超过 32,000 字符时才出现差异记录。
