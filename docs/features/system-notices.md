# 系统提示的表达与操作边界

日常提示只说明实际状态、用户受到的影响和一个必要的下一步。需要引导时给自然语言例句，不要求记命令。正常收件和成功提交保持安静；失败、结果未知和需要用户选择时仍由程序提示。

本次核对覆盖：升级发现与升级完成通知、模型切换后的重启提示、发送及附件失败、任务恢复与核对、项目归档/还原/不存在、历史分页、管理操作回执、模型未就绪提醒。

- 结果重发：“把刚才的文件再发一次”。原快照失效时明确无法重发，重新生成需用户另行提出；不自动重做业务任务。
- 未确认任务：“核对刚才的任务有没有完成”。保留未知状态，不从提示文字推导成功或重跑任务。
- 查询进展、服务及维护：“看看这个项目的结果”“检查助手是否正常”“升级完成了吗”。查询不自动切换项目或升级。
- 升级选择：“升级到这个版本”“这个版本先不升级”。仍需原管理流程核对版本、授权与忙闲状态。

以下提示保留准确格式要求，不伪称已支持任意自然语言答复：

1. 用户主动打开的应急帮助，以及模型不可用时的停止、服务状态和安装帮助兜底。
2. 已进入的编号选择、问题答复及批准/拒绝流程。模型不能代替用户批准，敏感内容不能转到聊天收集。
3. 首次安装、扫码、设备码、PIN、密钥输入和终端向导。模型尚未可用或需要本人操作，不能只提示用户让模型完成。

表达改动不改变上述解析和授权规则，也不把安装终端、开发 CLI、机器协议或模型提示词当作日常通知进行机械替换。消息发送未知时，不因文案变为自然语言而自动重发。
