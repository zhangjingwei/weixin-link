# Emergency commands when the model is unavailable

For daily queries and management, describe what you need; the current conversation model uses MCP as needed. See the [user guide](../../USER-GUIDE.en.md). These exact commands still work if the model cannot answer.

| Command | Purpose |
| --- | --- |
| `stop` | Stop the current conversation's task and clear its waiting queue; check the final stop result. |
| `exit` | Disconnect the current conversation while keeping its history. |
| `service-status` | Check this account's service status. |
| `guide` | Read the user guide. |
| `install-help`, `setup` | Read local installation and model setup instructions. |
| `install-agent`, `login-agent`, `check-agent` | Check Codex installation, read authorization instructions, or verify the connection. |

Follow the assistant's prompt to answer a pending approval or question. Desktop ownership recovery also has a separate entry. Do not send API keys or verification codes in WeChat.
