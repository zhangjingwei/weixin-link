# 模型不可用时的应急命令

日常查询和管理直接用自然语言提出，由当前会话模型按需调用 MCP。使用方法见[使用指南](../../USER-GUIDE.md)。以下精确命令在模型无法回答时仍由微信入口处理。

| 命令 | 用途 |
| --- | --- |
| `停止` | 停止当前会话任务并清空等待队列；最终停止结果仍需核对。 |
| `退出` | 断开当前会话，保留历史。 |
| `服务状态` | 查询当前账号服务状态。 |
| `使用说明` | 查看使用指南。 |
| `安装帮助`、`安装向导` | 查看本机安装与模型配置方法。 |
| `安装智能体`、`登录智能体`、`验收智能体` | 检查 Codex 安装、查看授权方法或执行连接验收。 |

审批与问题答复按助手发来的提示继续；它们是已有请求的协议回执。桌面端占用恢复也保留独立入口。不要在微信发送 API 密钥或验证码。
